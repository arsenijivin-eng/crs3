# CristyVPN Tasks Bot

## Запуск
1. Установите Python 3.10+.
2. Установите зависимости: `pip install -r requirements.txt`
3. Задайте токен через переменную окружения `BOT_TOKEN` (не публикуйте токен и не храните его в исходном коде).
4. Запустите: `python bot.py`

Linux/macOS:
```bash
export BOT_TOKEN="НОВЫЙ_ТОКЕН_ОТ_BOTFATHER"
python bot.py
```

Windows PowerShell:
```powershell
$env:BOT_TOKEN="НОВЫЙ_ТОКЕН_ОТ_BOTFATHER"
python bot.py
```

Первые администраторы: 7894051808 и 5969266721. База SQLite создаётся автоматически.
Пользователь может отправить до 50 фотографий в одной заявке. Администратор получает уведомление и может открыть заявку, увидеть все фото, начислить 1 звезду за каждый скрин, начислить частичную сумму или отказать с причиной. В меню админки доступны заявки на вывод, добавление администраторов и заданий.

## Важно
- Токен из переписки следует отозвать/перевыпустить в @BotFather и использовать новый.
- Отметка «выплачено» только фиксирует решение администратора; автоматического перевода денег/звёзд бот не делает.
- Не используйте задания для массового спама, фальшивых отзывов или скрытой рекламы. Тексты и условия заданий должны соответствовать правилам площадок и применимым требованиям к раскрытию рекламы.
